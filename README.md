This repository contains a list of more than 15000 operational amplifier netlists. For one- and two-stage opamps, structural and functional block annotations are provided, as well as sizings based on a simple transistor model.
The netlists were created by Markus Leibl from the Chair of Electronic Design Automation, TUM, in 2024.
The following tools were used:
https://github.com/inga000/acst 
https://github.com/markuslei/acst
